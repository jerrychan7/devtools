# @devtools-anywhere/devtools-frontend-locales

The UI translations of [@devtools-anywhere/devtools-frontend](https://www.npmjs.com/package/@devtools-anywhere/devtools-frontend) beyond English and Chinese. Serve `dist/` from the same directory as the frontend's `dist/`: the paths match, and a missing locale falls back to English. The Vite plugin and the remote server find it on their own when it is installed.

Use the same version as the frontend. See the [README](https://github.com/jerrychan7/devtools#readme) ([中文](https://github.com/jerrychan7/devtools/blob/main/README.zh-CN.md)). The translations are Chromium's (BSD-3-Clause).
